# Fancam Maker

เปลี่ยนคลิปคอนเสิร์ตแนวนอนให้เป็นแฟนแคมแนวตั้ง (9:16) ที่กล้องตามคนที่เราเลือกไปตลอดคลิป ทุกอย่างทำในเบราว์เซอร์ คลิปไม่ถูกอัปโหลดไปไหน

ลองได้ที่ https://namosarawut.github.io/fancam-maker/

## รันในเครื่อง

```bash
cd fancam/site
python3 serve.py
```

แล้วเปิด http://localhost:8000 ใช้ Chrome หรือ Edge จะลื่นสุด Safari ก็ใช้ได้

`serve.py` ใส่ header ที่ทำให้สแกนแบบหลายเธรดได้ (เร็วขึ้นราว 3–4 เท่า) และรองรับการเลื่อนดูคลิปแบบ HTTP Range
ถ้าจะเอาไปโฮสต์ที่อื่น อัปโหลดโฟลเดอร์ `site/` ทั้งโฟลเดอร์ได้เลย บน GitHub Pages ไฟล์ `coi-sw.js` จะจัดการเรื่อง header ให้เอง

## ใช้ยังไง

1. **ลากคลิปมาวาง** หรือแตะที่ช่องเพื่อเลือกไฟล์
2. **สแกนคลิป** เพื่อหาคนในทุกช่วงของคลิป คลิปยาว 1 นาทีกว่าๆ ใช้เวลาราว 1 นาที สแกนครั้งเดียวพอ เปิดคลิปเดิมครั้งหน้าไม่ต้องสแกนใหม่
3. **แตะคนที่อยากให้กล้องตาม** ถ้ากล้องไปตามคนอื่น ให้เลื่อนไปช่วงนั้นแล้วแตะคนที่ใช่อีกครั้ง (เรียกว่าการมาร์ก)
   - ในแถบไทม์ไลน์ สีเขียวคือเจอตัว สีเหลืองคือช่วงที่หาไม่เจอ ส่วนรูปข้าวหลามตัดคือจุดที่มาร์กไว้
   - ถ้าคนที่จะตามไม่มีกรอบขึ้น แตะกลางลำตัวเขาได้เลย
4. **ปรับกล้อง** ได้ทั้งขนาดคนในเฟรม ความนุ่มของกล้อง ฟีลกล้องถือมือ การจำกัดซูม สัดส่วน และความละเอียด
5. **ส่งออก** ใช้เวลาพอๆ กับความยาวคลิป ระหว่างนั้น**เปิดหน้านี้ค้างไว้** เสร็จแล้วกดดาวน์โหลด
