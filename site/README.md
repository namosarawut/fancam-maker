# Fancam Maker

ทำแฟนแคมแนวตั้ง (9:16) จากวิดีโอคอนเสิร์ตแนวนอน ทำงานในเบราว์เซอร์ทั้งหมด ไม่ต้องอัปโหลดไฟล์ไปที่ไหน

## เปิดใช้งาน

```bash
cd fancam/site
python3 serve.py
```

แล้วเปิด http://localhost:8000 ใน Chrome / Edge (แนะนำ) หรือ Safari

`serve.py` ส่ง header COOP/COEP เพื่อให้ ONNX Runtime ใช้ WASM หลายเธรดได้ (วิเคราะห์เร็วขึ้น ~3–4 เท่า) และรองรับ HTTP Range
ถ้าจะเอาไปโฮสต์ที่อื่น (Netlify, GitHub Pages ฯลฯ) อัปโหลดทั้งโฟลเดอร์ `site/` ได้เลย จะทำงานแบบ 1 เธรดถ้าโฮสต์ไม่ส่ง header ดังกล่าว

## วิธีใช้

1. **เลือกวิดีโอ** (แตะหรือลากไฟล์มาวาง)
2. **วิเคราะห์วิดีโอ**: ตรวจหาคนทุก 0.1 วินาที (คลิป 104 วิ ใช้ ~40–90 วิ) ผลจะถูกเก็บไว้ ครั้งหน้าเปิดไฟล์เดิมไม่ต้องวิเคราะห์ใหม่
3. **เลือกคนที่จะตาม**: หยุดวิดีโอแล้วแตะที่ตัวคน ถ้ากล้องตามผิดคนช่วงไหน ไปที่ช่วงนั้นแล้วแตะคนที่ถูก (เพิ่มจุดยึด)
   - แถบไทม์ไลน์: เขียว = เจอคนที่ตาม, เหลือง = หลุด (เดาตำแหน่ง), ขีดขาว = จุดยึด
   - ถ้าคนนั้นไม่มีกรอบ (ตัวตรวจจับมองไม่เห็น) แตะกลางลำตัวได้เลย
4. **ปรับกล้อง**: ขนาดคนในเฟรม, ความนุ่ม, กล้องสั่นแบบถือมือ, ซูมสูงสุด, สัดส่วน, ความละเอียด
5. **ส่งออกวิดีโอ**: อัดแบบเวลาจริง **ต้องเปิดหน้านี้ค้างไว้** จนเสร็จ แล้วกดดาวน์โหลด

คีย์ลัด: `Space` เล่น/หยุด · `←` `→` ทีละ 0.1 วิ · `N` ช่วงที่หลุดถัดไป · `Delete` ลบจุดยึดใกล้ตำแหน่งปัจจุบัน
